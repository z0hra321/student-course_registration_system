# WaitlistSystem

This folder contains the **WaitlistPQ** module skeleton and the extracted zip bundles for other teammate modules.

## WaitlistPQ module (paste your code here)
- `include/WaitlistPQ.h`
- `src/WaitlistPQ.cpp`
- (optional) `tests/test_waitlistpq.cpp`
- (optional) `main.cpp`

- `extracted/Huzaifa_GUI_Project_Files/` (from `Huzaifa_GUI_Project_Files.zip`)

## Build / link (optional)
There is a simple CMake config at `CMakeLists.txt` that builds:
- `waitlistpq` (library from `src/WaitlistPQ.cpp`, headers from `include/`)
- `waitlist_demo` (if `main.cpp` exists)
- `test_waitlistpq` (if `tests/test_waitlistpq.cpp` exists)
